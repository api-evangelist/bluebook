# Bluebook

> Bluebook builds AI agents for accounting firms, accountants, and CFOs. The platform automates accounting workflows — reconciliations, accruals, accounts payable and receivable, month-end close, reporting, and accounting research — toward a "zero-day close", integrating with the general ledgers firms already run on. Bluebook is a Stockholm, Sweden company founded in 2024, a Y Combinator Winter 2025 company, and raised a $3M pre-seed led by EQT Ventures.

## Important note for agents

Bluebook is a **product company, not an API provider**. As of 2026-07-20 it publishes:

- no public developer portal, API documentation, or API reference
- no machine-readable API description (OpenAPI, AsyncAPI, GraphQL schema, or Protobuf)
- no SDKs or client libraries in npm, PyPI, Maven Central, NuGet, pkg.go.dev, RubyGems, Packagist, or crates.io
- no CLI, no MCP server, no published Agent Skills
- no /.well-known/ discovery documents and no llms.txt of its own

Do not synthesize Bluebook API calls. There is no public API contract to call.

## Product surface

- Background Agents: accounts payable, accounts receivable, reconciliation, auditor, and reporting agents that run in the background against a firm's ledger.
- Checklists: tasks, delegation, human-in-the-loop approvals, and month-end close orchestration.
- Assistant: FP&A, flux analysis, and accounting research.
